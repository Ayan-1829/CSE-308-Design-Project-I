Economic feasibility formulas

payback period = development cost ÷ (annual benefit − annual running cost)
ROI = (total benefit − total cost) ÷ total cost × 100%
NPV = −initial cost + Σt=1..n net benefitt ÷ (1 + r)t
risk score = probability × impact (1–5 each)

IEEE SRS outline

  1. Introduction: purpose, conventions, audience, scope, references
  2. Overall description: perspective, features, user classes, environment, constraints, documentation, assumptions
  3. System features: description & priority, stimulus/response, functional requirements
  4. External interfaces: user, hardware, software, communications
  5. Non-functional: performance, safety, security, quality attributes, business rules
  6. Other requirements; appendices (glossary, models, TBD list)

Qualities of a good requirement

Correct · unambiguous · complete · consistent · ranked for importance · verifiable · modifiable · traceable. Write “The system shall …”, one idea, with an ID and a number for every quality.

Nielsen’s heuristics

  1. Visibility of system status
  2. Match between system and the real world
  3. User control and freedom
  4. Consistency and standards
  5. Error prevention
  6. Recognition rather than recall
  7. Flexibility and efficiency of use
  8. Aesthetic and minimalist design
  9. Help users recognise, diagnose and recover from errors
  10. Help and documentation
